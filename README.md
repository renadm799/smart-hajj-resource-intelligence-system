# Smart Hajj Resource Intelligence System (SHRIS)

## Project Overview

Smart Hajj Resource Intelligence System (SHRIS) is a team-developed prototype created for a university DataCamp competition.

The project explores how data analytics and machine learning can support resource planning during Hajj by analyzing factors such as crowd levels, temperature, health-related cases, and electricity consumption.

The prototype uses **synthetic data** for demonstration and experimentation.

## Tools & Technologies

- Python
- Pandas and NumPy
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning
- Data Visualization
- Jupyter Notebook

## Project Workflow

1. **Data Generation:** Created synthetic Hajj-related records for analysis.
2. **Data Cleaning:** Examined missing values, duplicates, data types, and outliers.
3. **Exploratory Data Analysis:** Investigated patterns across environmental, crowd, health, and resource variables.
4. **Machine Learning:** Explored predictive modeling approaches to support resource-related decisions.
5. **Visualization:** Presented findings and model outputs through charts.
